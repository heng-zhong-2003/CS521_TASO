# CS 521 ML & compilers 2025 final project: TASO rewrite synthesizer
An implementation of the graph rewrite synthesis algorithm of TASO for UIUC CS 521 ML and Compilers.

## Project proposal

[https://docs.google.com/document/d/1K0apsox7-EwkpIoMU_KXb8z0xjlwCRCVyFGNVxSRZkU/edit?usp=sharing](https://docs.google.com/document/d/1K0apsox7-EwkpIoMU_KXb8z0xjlwCRCVyFGNVxSRZkU/edit?usp=sharing)

## Running the experiment

First, ensure a Python of version 3.12. Then, run the following command to install the required packages.

```
pip install -r requirements.txt
```

To run the experiment, `cd` to the root directory of this project and run

```
python -m experiment.mlp
```
